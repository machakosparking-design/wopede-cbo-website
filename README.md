# WOPEDE - Women for Peace and Development CBO

Official website replication for [WOPEDE CBO](https://www.wopedecbo.org/).

## Overview
WOPEDE is a community-based organization located in Kenya that empowers refugee women, youth, and survivors of sexual and gender-based violence (SGBV) through skills training, peace-building, psychosocial support, and entrepreneurship.

## Tech Stack
* **Framework**: React 18 SPA
* **Router**: React Router v6
* **Styling**: Tailwind CSS
* **Icons**: Lucide React
* **Bundler**: Vite

## Deployment
This repository is configured for instantaneous static hosting on:
* **GitHub Pages**: Enabled via Settings > Pages (Source: Deploy from branch \main\, root \/\). Includes \.nojekyll\ and \404.html\ for Single Page Application client routing.
* **Vercel / Netlify**: Connect this repository for automatic deployment with custom domain (\wopedecbo.org\) and automatic HTTPS.
